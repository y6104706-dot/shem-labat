# שם לבת

משחק סוויפ לבחירת שם לבת, לשילת וניב. אפליקציית ווב (PWA) שמותקנת במסך הבית, עם סנכרון דרך Netlify Functions + Netlify Blobs.

- `index.html` — כל המשחק (2,170 שמות מנתוני הלמ"ס 1949–2024).
- `netlify/functions/sync.mjs` — `GET/PUT /api/sync?room=<קוד>&p=<shilat|niv>`.
- `sw.js` — עבודה בלי אינטרנט. בכל שחרור מעלים את `VERSION`.

הקישור האישי: `https://<האתר>/?k=<קוד-חדר>&p=shilat` (או `p=niv`). הקוד נשמר בטלפון בפעם הראשונה.

## שלבים
1. **גילוי** – סוויפים על המאגר. אחרי 25 התאמות (או 8 סבבים) כל אחד מסמן "סיימתי לגלות".
2. **סינון** – עד 4 שלבים, שאלה קשה יותר בכל שלב. שם עובר אם שניהם אמרו כן בלי היסוס; כן עם היסוס מקבל בחינה שנייה פעם אחת.
3. **דו-קרבות** – כשנשארים 6–12 שמות. חמשת המנצחים עולים לגמר.
4. **גמר** – ניתוח מעמיק לכל שם, ראיון אישי לכל אחד, ודוח משותף (Claude, דרך `netlify/functions/ai.mjs`).

## הגדרה
- `ANTHROPIC_API_KEY` במשתני הסביבה של Netlify (Functions). אופציונלי: `AI_MODEL_FAST`, `AI_MODEL_DEEP`.
- `Content-Security-Policy: script-src 'self'` ב-`netlify.toml` – כל הקוד ב-`app.js`; זה גם חוסם את תג "Powered by Netlify".
